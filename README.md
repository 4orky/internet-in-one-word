One word for the whole internet. The program writes it to `/output/entry.txt`:

> enshittification

Why this word: it is a real word (American Dialect Society 2023 Word of the Year) coined for exactly this — platforms decaying as they squeeze users and advertisers alike. It is funny on its own, true about the internet as a whole rather than one app, surprising, and a single word. Fifteen hand-scored candidates were weighed against the judge's brief (funny, true about the whole internet, surprising, lands in one beat); a second-pass revision corrected the early leader "feral" — wildness in general, not the internet — and "enshittification" won on truth and surprise by more than it loses on brevity.

## Run it

```sh
python3 main.py
```
